# AI-Powered Data Analysis Dashboard

## Project Overview
The AI-Powered Data Analysis Dashboard is a Python-based web application that helps users upload, clean, explore, visualize, and analyze datasets interactively. It generates automated statistical insights to support data-driven decision-making.

## Features
- **Dataset Upload:** Supports CSV, Excel, and JSON files.
- **Data Preprocessing:** Handles missing values and duplicate records.
- **Dataset Overview:** Displays rows, columns, data types, and missing-value summaries.
- **Interactive Visualizations:** Creates bar charts, line charts, pie charts, histograms, scatter plots, and correlation heatmaps.
- **Automated Insights:** Identifies statistical patterns and potential outliers.
- **Business Analytics:** Displays revenue metrics, product comparisons, and monthly trends.
- **Search and Filtering:** Helps users explore specific records.
- **Data Export:** Downloads cleaned and filtered datasets as CSV files.

## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
- OpenPyXL

## Installation and Setup

1. Clone this repository.
2. Install the dependencies:

   `python -m pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`

4. Upload a dataset and explore the dashboard.
